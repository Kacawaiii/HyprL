Revision 11 (`replay_duel_spec_v7.json`) records the operator's blanket decision before any replay answer was read or graded. There is no repair, extra collection, label retry or outcome-dependent selection.

The input builder records reason counts, subject-set digests and excluded-day counts in the private, sealed manifests. A missing benchmark or missing day coverage excludes the whole day's contexts. Such contexts produce empty paired replay records without consuming model calls. Forward records the shared exclusion and publishes its snapshot/failure hashes before the open. Invalid source clocks, metadata and bars are excluded before candidate ranking. Existing history and liquidity eligibility filters remain unchanged and are reported separately by reason.

The outcome reader returns shared exclusions for missing fills, marks, labels and source requests. A request absent from the sealed cache is distinct from a missing or altered object that was bound by the seal. Bound-object damage, request/object hash mismatches, programming errors and model validation failures still fail closed.
